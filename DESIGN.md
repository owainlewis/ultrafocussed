# Planner design

The planner is an Operate surface. A weekly board is the complete application, with an unscheduled rail and a task detail panel. A warm neutral canvas and fine column rules give the work most of the space. Forest green identifies today and the primary action. System sans type keeps compact controls readable.

Desktop presents five day columns; weekends expand on request and remain discoverable when tasks are scheduled there. Mobile presents a day strip, one selected day's tasks, and an unscheduled drawer. Editing uses a native dialog styled as a side panel, with keyboard focus contained and restored. No decorative animation or generated imagery is needed.

Empty columns offer inline task capture. Completed tasks remain visible. Previous unfinished tasks appear separately in the unscheduled rail and never move automatically. Error notices preserve the user's work and name the recovery action.
